# FirstStep Academy

## Your First Step to Learning, Building Skills, and Earning Online

A professional, scalable online learning platform designed for beginners who want to learn digital skills, overcome fear, build confidence, and start making money online.

### 🚀 Features

- **Learning Pathways**: Free courses, roadmaps, video lessons, and interactive tasks
- **Content Hub**: Blog, AI tools directory, product reviews, resource library
- **Community**: Forum, success stories, gamification (XP, badges, streaks)
- **Monetization**: Google AdSense integration, affiliate marketing system
- **Admin Dashboard**: Content management, user management, analytics
- **Security**: HTTPS, authentication, CSRF/XSS protection, rate limiting
- **SEO Optimized**: Schema.org, Open Graph, XML sitemap, structured data
- **Mobile First**: Fully responsive, PWA-ready, fast loading

### 🛠 Tech Stack

**Frontend:**
- Next.js 14
- React 18
- Tailwind CSS
- Framer Motion (animations)
- Zustand (state management)

**Backend:**
- Node.js + Express
- PostgreSQL
- Clerk (authentication)

**Services:**
- Cloudinary (media storage)
- Stripe (payments)
- Nodemailer (email)
- Google AdSense API

### 🔧 Getting Started

1. Clone and install:
   ```bash
   git clone https://github.com/chidejoyc/firststep-academy.git
   cd firststep-academy
   npm install
   ```

2. Set up environment:
   ```bash
   cp .env.example .env.local
   ```

3. Run development server:
   ```bash
   npm run dev
   ```
